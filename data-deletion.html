Data Deletion Instructions

Grimborn: The Awakening (Android) · last updated 1 November 2026

ReveoBlade operates no server that stores player accounts, so there is no remote copy of your data to delete. Everything the game holds lives on your device and is removed by the steps below.

Delete the Facebook profile the game stored

  1. Open Grimborn: The Awakening.
  2. Tap ⚙ Settings, then Facebook Account.
  3. Tap Sign Out and confirm. The stored name and photo are erased and the Facebook session held by the app ends.
  4. Optionally, remove the game from your Facebook apps: open Facebook → Settings & privacy → Settings → Apps and websites, find Grimborn: The Awakening and choose Remove.

Delete all game progress

  1. Uninstall Grimborn: The Awakening from your phone (long-press the icon → App info → Uninstall).
  2. That removes the save file, gear, settings and any stored account details in one step.

If you want to keep your progress across devices, export a Save Code from Settings before uninstalling — that text is the only copy that travels with you.

Request help

If you would like confirmation that nothing is held about you, or you need help with the steps above, email itsreveobladeplays@gmail.com with the subject Data deletion. Because no server store exists, we can only confirm that fact and walk you through the on-device steps; there is no remote record to remove.

Online play

Room codes, hunter names and moves pass through a public message relay while a duel or hunt is running and are not retained afterwards. Nothing needs to be deleted from it.
